# Folio

Folio is a free Windows desktop book formatter: a practical, local alternative to Vellum for authors who want to edit, style, preview, and export a complete book from one application.

[Download Folio for Windows](https://github.com/deletethisbozo-hue/Folio/releases/tag/v0.2.0)

The release is self-contained. Readers do not install Node.js, Pandoc, Chromium, Java, or any command-line tools.

## What Folio does

- Native-feeling three-pane workspace: book structure, manuscript editor, and live preview.
- Live Kindle preview driven directly by the current editor draft, independent of autosave.
- Print preview generated by the same Paged.js/Chromium pipeline as the final print PDF.
- Visual style library with 20 complete designs: Classic, Modern, Decorative, Literary, Editorial, Heritage, Scholar, Folio, Ivory, Nocturne, Cloister, Blackletter, Parchment, Atlas, Stanza, Aubade, Ember, Cinder, Solstice, and Timber.
- Book-level typography controls for body text, chapter headings, first paragraphs, scene breaks, headers/footers, and title pages.
- Reliable copy-on-write editing for the bundled sample and exact source-path editing for real books.
- EPUB for Kindle/KDP, universal EPUB, print PDF, reading PDF, and DOCX export.
- Popular print trims: 5 × 8, 5.25 × 8, 5.5 × 8.5, 6 × 9, and 8.5 × 11 inches.
- Running heads, folios, mirrored margins, page-aware gutters, recto chapter openings, and a printed contents page.

## Book folder format

Folio opens an ordinary folder. A structured book uses `book.yaml` plus Markdown files:

```text
my-book/
  book.yaml
  cover.png
  frontmatter/
    dedication.md
  chapters/
    01-the-letter.md
    02-the-garden.md
  backmatter/
    about-the-author.md
```

Minimal `book.yaml`:

```yaml
title: The Clockwork Garden
subtitle: A Novel
author: Eleanor Vance
language: en
theme: folio
cover: cover.png
frontmatter:
  - titlepage
  - copyright
  - frontmatter/dedication.md
chapters: chapters
backmatter:
  - backmatter/about-the-author.md
```

Each Markdown chapter begins with a top-level heading. `---` creates a scene break; ordinary Markdown bold and italic are supported, and Folio's toolbar can insert bold, italic, underline, and scene breaks directly.

## Themes and typography

Every theme is real CSS shared by preview and export, not a renamed palette. Themes define body type, chapter openings, subtitles, first-paragraph treatment, drop caps, scene ornaments, title/copyright matter, back matter, and print behavior. Per-book overrides are stored under `typography:` in `book.yaml` only when the author chooses **Save to Book**.

## Export behavior

Books opened from disk write versioned files to the book's configured export folder. The bundled sample and uploaded copies return download data to the desktop UI. Folio never edits files inside `app.asar`; the sample is copied to Folio's writable application data on its first edit.

## Development

The installable release has no external runtime requirements. Building Folio from source requires Node.js 22; Pandoc and a Puppeteer-compatible Chromium are needed for local export tests.

```bash
npm ci
npm run typecheck
npm test
npm run build
```

Windows release packaging and packaged-runtime smoke tests live in [`.github/workflows/windows-release.yml`](.github/workflows/windows-release.yml). The workflow bundles Pandoc and Chrome Headless Shell, builds both installer and portable executables, launches the packaged application, exercises its API, edits the sample, renders live and print previews, and generates EPUB and PDF files before publishing the release.
